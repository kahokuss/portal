# 河北SS ポータル（保護者LINEグループ用）

- ポータル：https://kahokuss.github.io/portal/
- このリポジトリは公開されています。**保護者や子どもの名前、トークンなどの秘密の値は入れないでください**（データはクラブ共用アカウントのスプレッドシート・カレンダーにあります）

小学生陸上クラブの保護者向けに、次のものをまとめた仕組みです。

- **ポータル**：予定・大会・エントリー・休みの連絡を、スマホで見て操作できるページ。**クラブのLINEグループのメンバーだけ**が、LINEでログインして見られます
- **LINE Bot**：グループに入れておくと、写真を保存し、結果を記録し、ポータルのリンクを返します

**いまのLINEグループはそのまま使えます**。Botはメンバーの1人として加わるだけで、ふだんの会話や連絡はこれまでどおりです。

これまでトークに流れていた欠席連絡や大会案内を、1か所にまとめます。

サーバー代はかかりません。**Google Apps Script（無料）** の上で動き、データは **Googleスプレッドシート・カレンダー・ドライブ** に入ります。
すべてを**クラブ共用のGoogleアカウント**に置くので、役員が交代しても、ログイン情報を引き継ぐだけで続けられます。

| ⏰ 手続きの締切 | エントリーの提出・参加費の支払い・当日の受付・リレー予選/決勝のオーダー提出に「何時まで」を入れられる。近づくと色が変わり「あと40分」と表示。役員のBot「新着」にも出る |

| 🗳 アンケート | 役員が質問と選択肢（参加/不参加、○/× などのひな形あり）をつくると、ホームにボタンで出て、家族で1つ回答。結果のグラフ、だれが答えたか・まだの家族（役員）、結果をLINE用にコピー |

| ⏱ タイムテーブル | プログラムを貼り付けると、時刻・学年・男女・種目・組・招集を読み取ります。**わが家の子の種目だけ**、または学年ごとに見られます。アップの目安（招集の30分前）と、大会の日は「次の招集まであと何分」も出ます |
| ☑ 大会の手続き | エントリー提出（控えの写真）、集金、プログラム（写真）、招集（子ども・種目ごと）、リレー予選・決勝のメンバー報告を、チェックリストで進めます |
| 📷 写真（アルバム） | グループに送った写真は、共用アカウントのGoogleドライブに大会・練習ごとに自動で保存し、**ポータルの「写真」で見られます**（LINEグループのメンバーだけ）。保存・ポータルから上げる・消す（上げた人と役員）ができます。ドライブのフォルダは保護者に共有しません |
| 🧹 当番表 | 練習当番と大会当番を別々に数えます。前回から日がたっている家族から順に表示し、自動で入れることもできます |
| 🏃 ダウン（お迎えの合図） | グループに「ダウン入ります」と送ると、Botが返事をせずに時刻だけ記録し、ポータルの今日の練習とBotの「今日」に「ダウンに入りました（17:55）」と出る。当番・役員は「ダウンに入った」ボタンから、文面入りでLINEのグループに送れる |
| 📣 LINEの変更連絡 | グループに「次の木曜日の練習は16時50分から競技場で」「明日の練習は中止です」と流れると、Botは返事をせずにその日の練習に結びつけて残す。ポータルの練習のページ・予定一覧・ホーム、Botの「今日」「予定」に出て、役員は「予定に反映する」ボタン1つでGoogleカレンダーを直せる（中止・予定にない日の練習づくりも） |
| 🙋 休みの連絡 | 保護者がポータルかBot（「休み 明日」）で連絡。グループには流れない。**LINEの通知はしない**（通数の節約）。役員はBotの「新着」「出欠」とポータル、当番の家族はBotの「新着」で休む子が分かる。**だれが休みかの出欠一覧**は練習のページでみんなが見られる（理由は本人と役員だけ）。通知を戻すときは Config.gs の ABSENCE_PUSH_TO_ADMINS を true |
| 💬 コメント・⚠ヒヤリハット | 練習・大会のページに、保護者がコメントを書けます。**ヒヤリハット**（けがにはならなかったが危なかったこと）は目立つ色で共有し、役員にLINEで届き、役員が対策を書きこみます。ホームに最近の報告、管理メニューに一覧。「役員だけに見せる」もできます |
| 📢 お知らせ・一斉通知 | 役員が書くとホームに載ります。**重要**の印を付けられ、未読には赤い点。役員には「既読 5/12人」とまだ読んでいない人が出ます。LINEに貼る文章をコピー（無料）するか、**BotからLINEグループ全員に送れます**（人数分の通数を使うので、今月の残りを表示し、足りなければ送りません） |
| 🔒 Botの返事 | グループで「ヘルプ」「ポータル」「記録」などを送っても、返事は**送った人にだけ**1対1で届きます（グループには出ません） |
| 👪 わが家 | 子どもの名前・学年・男女を登録します。**招待番号で夫婦を同じ家族にまとめる**と、子どもの登録・当番が共通になります |
| 🏃 結果・記録 | 大会のページの「結果」で入れる（LINEの `結果 100m 15.2秒` でも）。記録は**公式（大会）と練習を分けて**、ベストも別々に出す。わが家に**種目ごとの自己ベストと、記録の移り変わりのグラフ**（上ほどよい記録・★が自己ベスト）。役員は「記録・自己ベスト表」で種目ごとの一覧・グラフ・表計算へのコピー、**過去の記録の取り込み**（Excel・スプレッドシートの表をそのまま貼り付け、または .xlsx/.csv をドロップ。横に種目が並ぶ表もOK） |
| ↩ LINEへ | ポータルの上のバーの「LINEへ」で、LINEのトーク一覧に戻れます |

この先の予定：記録の一覧と自己ベスト、体育館のかぎ当番

## 保護者の使い方

1. グループに貼ってあるポータルのリンクを開きます。Botに `ポータル` と送っても、リンクが返ってきます
2. 「**LINEでログイン**」を押します。LINEアプリの中で開けば、許可を押すだけです
3. はじめての人は「わが家」で、お子さんの名前と学年を登録します

- 入れるのは、**クラブのLINEグループに入っている人だけ**です。リンクがほかの人に渡っても、グループのメンバーでなければ見られません
- グループを抜けた人は、半日ほどでポータルを使えなくなります
- 友だち追加は不要です。ただし役員は、休みの連絡をLINEで受け取るためにBotを友だち追加してください
- 一度ログインすると、同じスマホでは次からログインなしで開けます。家族で1台のスマホを使うときは、「わが家」の「ログアウト」から切り替えてください

| Botに送る言葉 | 何が起きるか |
|---|---|
| `新着` | 次の練習・わが家の当番・エントリーの未回答・新しいお知らせ・ヒヤリハットをまとめて。役員には確認待ちの休み・対策待ちのヒヤリハット・当番が決まっていない予定も |
| `今日` | 今日の予定。大会の日は、わが家の子の時刻・招集・ナンバー・レーン |
| `予定` | これからの予定 |
| `休み` | 休みの連絡。ボタンで日にちを選べる。`休み 明日`、`休み たろう 10/20 体調不良` でもOK。`休み取消` で取り消し |
| `当番` | わが家の当番と、これからの当番 |
| `出欠` | 次の練習で休む人 |
| `エントリー` | 大会のエントリーの状況と締切 |
| `ポータル` | ポータルのリンク |
| `登録 名前 学年` | 子どもを登録（ポータルの「わが家」からもできます） |
| `結果 100m 15.2秒` | 結果を記録 |
| `記録` | 子どもの記録一覧 |
| `写真` | アルバムのリンク |
| `ヘルプ` | 使い方 |

- Botの返事には、よく使う言葉のボタンが付きます。Botとの1対1のトークの下には、メニュー（新着・今日・休み・予定・当番・ポータル）も出せます（エディタで `setupRichMenu` を1回実行）
- 返事はすべて、送った人にだけ届きます。1対1のトークで送れば通数はかかりません

普段の会話には反応しません。反応するのは、メッセージの最初の言葉が上の言葉と完全に一致したときだけです。

### 見えるもの

- 予定・大会の案内・みんなのエントリー・集金の状況・お知らせ：**メンバー全員**
- 休みの連絡：**だれが休みか**はメンバー全員（いままでのトークと同じ）。**理由とひとこと**は、連絡した本人と役員だけ
- 大会の案内づくり・予定づくり・当番の割り当て・集金のチェック・休みの確認・お知らせ：**役員だけ**
- タイムテーブルの入力、大会の手続き（提出・プログラム・リレー）：**役員と、その大会の当番の家族**
- 招集の「招集した」、写真を上げる：**メンバー全員**（会場で助け合えるように）

## 更新のしかた（Apps Script）

1. PCで [dist/Code.gs](https://raw.githubusercontent.com/kahokuss/portal/main/dist/Code.gs) を開き、全部選んでコピーします
2. Apps Script のエディタで「コード.gs」の中身を全部消して貼り付け、保存します
3. 「デプロイ」→「デプロイを管理」→ 鉛筆（編集）→ バージョン「新バージョン」→「デプロイ」（**「新しいデプロイ」は使わない**。URLが変わってしまいます）
4. 新しいシートやトリガーが増えたときは、関数 `setup` をもう一度実行します（何度実行しても大丈夫です）

画面（docs/index.html）は GitHub Pages なので、このリポジトリに push するだけで変わります。

## セットアップ（役員・係の方向け、1時間ほど）

### 0. クラブ共用のGoogleアカウントを作る

1. クラブ用のGoogleアカウント（例：`kahoku.ss@gmail.com`）を新しく作ります
2. 以下の作業は、**すべてこのアカウントでログインして**行います。カレンダー・スプレッドシート・写真・プログラムが全部ここに入ります
3. 引き継ぎのため、次のことをしておいてください
   - パスワードと再設定用の電話番号・メールを、役員の引き継ぎ資料に書いておく
   - 2段階認証の電話番号は、役員が交代したら付け替える
   - 念のため、スプレッドシートとカレンダーを役員個人のアカウントにも「編集者」で共有しておく（共用アカウントに入れなくなったときの保険）

### 1. LINE公式アカウントとMessaging APIを用意する

1. [LINE Developers](https://developers.line.biz/) にログインし、プロバイダーと**Messaging APIチャネル**を作ります
2. 「Messaging API設定」で**チャネルアクセストークン（長期）**を発行してメモします
3. [LINE Official Account Manager](https://manager.line.biz/) で次の設定をします
   - 「アカウント設定」で**グループ・複数人チャットへの参加を許可する**をオン
   - 「応答設定」で**応答メッセージをオフ**、**Webhookをオン**
4. 同じプロバイダーの中に、**LINEログイン**のチャネルをもう1つ作ります（ポータルのログイン用）
   - アプリタイプは「ウェブアプリ」
   - 「チャネル基本設定」の**チャネルID**と**チャネルシークレット**をメモします
   - コールバックURLは、手順5でWebアプリのURLができてから登録します
   - 公開状態を「公開済み」にします（開発中のままだと、チャネルの管理者しかログインできません）
   - **Messaging API と同じプロバイダー**に作ってください。違うプロバイダーだと、同じ人でもユーザーIDが変わり、グループのメンバー確認ができません

### 2. Googleカレンダーを用意する

1. 共用アカウントで、クラブ用のカレンダーを作ります
2. 練習は**繰り返しの予定**で入れておくと楽です
3. 「設定と共有 > カレンダーの統合」にある**カレンダーID**をメモします
4. 保護者にカレンダーを共有しておくと、各自のスマホのカレンダーでも予定が見られます

### 3. Apps Scriptにコードを入れる

**方法A：ブラウザでコピー＆ペースト**

1. 共用アカウントで [script.google.com](https://script.google.com/) を開き、「新しいプロジェクト」を作ります
2. `src/` にある `.gs` ファイルと `Portal.html` を、同じ名前でエディタに作って貼り付けます。HTMLは「＋ → HTML」で作り、名前は `Portal` にします
3. 「プロジェクトの設定」で「appsscript.json マニフェストファイルをエディタで表示する」をオンにし、`src/appsscript.json` の内容を貼り付けます

**方法B：clasp を使う（開発者向け）**

```sh
npm install -g @google/clasp
clasp login            # 共用アカウントでログイン
clasp create --type standalone --title "河北SS ポータル" --rootDir src
clasp push
```

### 4. スクリプト プロパティを設定して setup を実行する

1. 「プロジェクトの設定 > スクリプト プロパティ」に次の4つを追加します
   - `LINE_CHANNEL_ACCESS_TOKEN`：手順1のトークン
   - `LINE_LOGIN_CHANNEL_ID`／`LINE_LOGIN_CHANNEL_SECRET`：手順1-4のLINEログインのチャネルIDとシークレット
   - `CALENDAR_ID`：手順2のカレンダーID
2. エディタで関数 `setup` を選んで「実行」し、権限を許可します
3. ログに表示されるスプレッドシートと写真フォルダのURLを、役員で共有しておきます

### 5. Webアプリとして公開し、LINEにWebhook URLを登録する

1. 「デプロイ > 新しいデプロイ > 種類：ウェブアプリ」を選びます
   - 次のユーザーとして実行：**自分**（共用アカウント）
   - アクセスできるユーザー：**全員**
2. ウェブアプリのURLの末尾に `?token=` とスクリプト プロパティ `WEBHOOK_TOKEN` の値を付けて、LINE Developersの「Webhook URL」に登録します
   - 例：`https://script.google.com/macros/s/xxxx/exec?token=abcd1234...`
   - 「検証」ボタンはエラーになることがあります（Apps Scriptはリダイレクトで応答するためです）。実際のメッセージは届きます
3. LINEログインのチャネルの「LINEログイン設定 > コールバックURL」に、**ウェブアプリのURL（`?token=` を付けないもの）**を登録します
4. このURLが、ポータルのリンクになります

> コードを更新したときは、「デプロイを管理 > 編集 > バージョン：新バージョン」で**同じデプロイを更新**してください。新しいデプロイを作るとURLが変わってしまいます。

### 6. グループに招待して、役員を決める

1. いまの保護者のLINEグループにBotを招待します。グループIDが自動で保存され、このグループのメンバーだけがポータルに入れるようになります
2. 役員の方は、ポータルに一度ログインしてから、スプレッドシートの「**家族**」シートで自分の行の「役員」欄に `○` を入れます。ポータルに「管理」メニューが出るようになります
3. 役員の方は、Botを友だち追加しておきます。休みの連絡がLINEで届くようになります
4. グループにポータルのリンクを投稿し、ノートやアナウンスに固定しておきます。「LINEでログインして、『わが家』でお子さんを登録してください」と案内します

## 設定の変更

`src/Config.gs` の `CONFIG` で変えられます。

| 項目 | 内容 |
|---|---|
| `CLUB_NAME` | クラブ名 |
| `RACE_KEYWORDS` | 予定名にこの言葉があれば大会として扱う。ポータルの予定から、1件ずつ「大会／練習」を切り替えることもできます |
| `DEADLINE_DAYS_BEFORE` | 大会を作るとき、締切を何日前に自動で入れるか |
| `ABSENCE_PUSH_TO_ADMINS` | 休みの連絡を役員にLINEで知らせるか |
| `SAVE_ALL_PHOTOS` | グループの写真を自動で保存するか |

種目・持ち物・対象・休みの理由の候補は `CHOICES` で変えられます。

## データ（スプレッドシート）

| シート | 中身 |
|---|---|
| 家族 | LINEのユーザー、表示名、ログインのキー、役員（○）、グループのメンバーを最後に確認した日時 |
| 子ども | 名前、学年、保護者（両親で登録すると2人入ります） |
| 予定 | カレンダーから取り込んだ予定 |
| 大会 | 大会ごとの案内（対象・参加費・締切・集合・種目・持ち物・注意） |
| エントリー | 子どもごとの参加・不参加、種目、集金 |
| 休み | 休みの連絡と、役員の確認 |
| お知らせ | ホームに載せるお知らせ |
| 写真・結果 | 保存した写真の一覧、レース結果 |

学年は4月に、各家庭が「わが家」で上げるか、役員がスプレッドシートの「子ども」シートで直してください。

## 注意点

- **メッセージ通数**：Botの返信は無料です。通数を使うのは、休みの連絡を役員に知らせるときだけで、1件につき役員の人数分です。たとえば役員2人で月30件なら60通となり、無料枠（月200通）に収まります。足りなくなったら `ABSENCE_PUSH_TO_ADMINS` を `false` にして、役員はポータルで確認してください
- **役員へのLINE通知**は、Botを友だち追加している役員にだけ届きます
- **個人情報**：スプレッドシートと写真フォルダは共用アカウントのドライブにあります。共有するのは役員だけにし、「リンクを知っている全員」での公開はしないでください
- **ポータルに入れる人**：LINEでログインし、Botが入っているグループのメンバーと確認できた人だけです。メンバーかどうかは、12時間ごとに確かめ直します（`MEMBER_RECHECK_HOURS`）
- グループのメンバー確認には、Botがそのグループに入っている必要があります。Botをグループから外すと、だれもポータルに入れなくなります
- Apps ScriptのWebアプリには、ページ上部に「Googleではなく他のユーザーが作成したアプリです」という表示が出ます。Googleの仕様なので、気にしなくて大丈夫です
- Apps ScriptではLINEの署名ヘッダーを検証できません。代わりに、Webhook URLの `token` で不正なリクエストを弾いています

## しくみ（どこに何があるか）

| もの | 場所 |
|---|---|
| ポータルの画面 | このリポジトリの `docs/index.html` を GitHub Pages で公開（`src/Portal.html` から `node tools/build-pages.js` で作る） |
| サーバー（LINE Bot・データの読み書き） | クラブ共用アカウントの Apps Script（`src/*.gs`）。画面からは、ウェブアプリの URL に POST して使う |
| データ | クラブ共用アカウントのスプレッドシート・カレンダー・ドライブ |

画面の場所と、Apps Script のウェブアプリの URL は `pages.config.json` に書いてあります。

## 開発

```sh
node tools/build-pages.js  # src/Portal.html を直したら、docs/index.html を作り直す
npm test                 # サーバー側のテスト（Apps Script のサービスはメモリ上のまねで動かす）
npm i && npm run test:e2e  # ポータル画面を実際のブラウザで動かすテスト（Playwright）
node tests/e2e.js --shots  # 画面を tests/screenshots/ に保存
```

`tests/gas-mock.js` は、スプレッドシート・カレンダー・LINE APIなどをメモリ上でまねて、`src/*.gs` をそのまま Node.js で動かします。
